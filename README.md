# Escola 2º Ano

Repositório com os projetos e atividades desenvolvidos durante o 2º ano do curso de Informática para Internet da ETEC Francisco Morato, em 2026.

## Sobre o projeto

Este repositório reúne materiais e trabalhos relacionados às disciplinas e áreas de estudo do curso, incluindo:

- PHP
- HTML
- CSS
- JavaScript
- Banco de Dados (MySQL)
- Nuvem
- Android
- Interfaces Web II

## Estrutura do repositório

- `PHP/` — projetos e exercícios em PHP
- `BANCO DE DADOS/` — atividades de banco de dados e SQL
- `NUVEM/` — estudos e práticas de computação em nuvem
- `ANDROID/` — aplicações e materiais relacionados a Android
- `INTERFACES WEB II/` — atividades de desenvolvimento web e interfaces
- `Aula 04 - JavaScript (1).pptx` — material de aula

## Objetivo

Organizar e centralizar os projetos, exercícios e materiais estudados ao longo do ano, facilitando o acompanhamento do aprendizado em programação, desenvolvimento web, banco de dados e tecnologias mobile/cloud.

## Tecnologias principais

- Front-end: HTML, CSS, JavaScript
- Back-end: PHP
- Banco de Dados: MySQL
- Mobile: Android
- Infraestrutura e cloud: Nuvem

## Status

Em desenvolvimento, com conteúdos e projetos sendo adicionados ao longo do curso.
